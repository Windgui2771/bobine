# Installer Bobine sur Windows

Bobine existe en appli Windows (Windows 10 et 11, 64 bits). Elle s'ouvre en grand, se pilote à la souris, au clavier ou avec une manette Xbox branchée au PC, et fonctionne sans navigateur.

## Installation

1. Dans les [Releases](../../../releases/latest), télécharge l'un des deux fichiers :
   - **`Bobine-X.Y.Z-installation.exe`** : installe Bobine, avec un raccourci sur le bureau et dans le menu Démarrer (conseillé) ;
   - **`Bobine-X.Y.Z-portable.exe`** : se lance sans installation, pratique sur une clé USB.
2. Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur ». C'est normal : l'appli n'est pas signée par un certificat payant. Clique sur **Informations complémentaires**, puis sur **Exécuter quand même**.
3. Saisis l'adresse de ton Jellyfin, éventuellement l'[adresse extérieure](acces-exterieur.md), puis connecte-toi.

## Raccourcis

| Touche | Action |
|---|---|
| **F11** | plein écran / fenêtre |
| Flèches, Entrée, Échap | naviguer, valider, revenir |
| Espace | lecture / pause |

Pendant une vidéo, l'appli passe toute seule en plein écran.

## Demandes (Seerr)

Renseigne l'adresse de Seerr dans **Profil → Réglages** (ou *Tableau de bord → Réglages appli*).

## Désinstaller

*Paramètres Windows → Applications → Bobine → Désinstaller.*
